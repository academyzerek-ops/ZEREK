# Решения маслихатов о ставках УД (упрощённой декларации)

> Базовая ставка УД по НК РК 2026 — 4% (Ст. 726). Местные представительные органы (маслихаты) вправе понижать или повышать её на ±50% — то есть устанавливать в диапазоне 2-6%.
> Конкретные ставки по 20 городам зафиксированы в `data/external/kz_tax_constants_2026.yaml` под ключом `usn.municipality_rates` — это **SoT для кода**.
> Эта папка — **скачанные оригиналы решений маслихатов** (первоисточники).

## Чего здесь нет (и почему)

В SoT yaml у нас данные по 20 городам (Астана, Алматы, Шымкент, областные центры и новые областные центры). Из них **только Актобе подтверждён оригиналом решения**. По остальным 19 городам ставки взяты из сводок (mybuh.kz, Vita Liberta, конкретные ссылки на решения маслихатов с adilet.zan.kz) — это надёжно для практики, но не первоисточник.

Чтобы заполнить пробел — скачать с adilet.zan.kz решения маслихатов всех 20 городов (по одному файлу в эту папку) и подключить пакетом.

## Когда обновлять

Маслихаты принимают решения **до 1 декабря** на следующий год. Каждый декабрь — проверять обновления и пересохранять файлы здесь, синхронизируя с SoT yaml.
