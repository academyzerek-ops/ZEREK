# Приказ Минфина №695 — формы налоговой отчётности на 2026

> **Приказ Министра финансов РК №695 от 12.11.2025.**
> Зарегистрирован в Минюсте РК 12.11.2025 № 37390.
> Вводится в действие с 01.01.2026.
> Утверждает формы деклараций и расчётов по налогам и социальным платежам, а также правила их представления.

## Что внутри

[`_full.md`](_full.md) — полный текст приказа (~1.4 МБ markdown). Содержит формы и правила их составления.

## Список форм

Приказ утверждает следующие основные формы (приложения к приказу):

| Форма | Назначение | Кому подавать |
|---|---|---|
| **100.00** | Декларация по КПН | ТОО на ОУР |
| **101.02** | Расчёт авансовых платежей по КПН после декларации | ТОО на ОУР |
| **101.03** | Расчёт КПН у источника выплаты с дохода резидента | Налоговые агенты |
| **101.04** | Расчёт КПН у источника выплаты с дохода нерезидента | Налоговые агенты |
| **110.00** | Декларация по КПН (для НКО, фондов и др.) | НКО, фонды |
| **150.00** | Декларация по КПН и налогу на сверхприбыль | Недропользователи |
| **200.00** | Декларация по ИПН и социальному налогу | Все работодатели — **ежеквартально** |
| **220.00** | Декларация по ИПН (для физлиц) | Физлица с доходами вне трудового найма |
| **250.00** | Декларация об активах и обязательствах физлица | Физлица (всеобщее декларирование) |
| **910.00** | Упрощённая декларация для СНР | ИП и ТОО на УД — **раз в полугодие** |

## Использование в продуктах ZEREK

- **Quick Check / FinModel:** автоматически рассчитывает суммы для форм 200.00 и 910.00 на основе заявленного дохода и ФОТ.
- **BizPlan:** в разделе «Налоговая модель» цитирует, какие формы нужно сдавать в этом режиме и с какой периодичностью.
- **Академия:** генератор тестов по формам отчётности использует этот приказ как эталонный источник.
- **AI-консультации (Mini App):** при вопросах «как заполнить ф.910» или «когда сдавать ф.200» RAG отдаёт релевантный фрагмент из этого файла.
