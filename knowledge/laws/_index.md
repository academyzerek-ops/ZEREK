# Законы и подзаконные акты — оглавление

> Действующие первоисточники законодательства РК для RAG-индексации.
> Все файлы конвертированы из docx с ИЗПИ / adilet.zan.kz.
> Каждый файл имеет frontmatter с `law_number`, `current_redaction`, `sha256` исходника.

## Что здесь

Законы общеотраслевые, не налоговые. Налоговые законы и подзаконные акты — в `knowledge/taxes/`.

## Налоговое законодательство

Лежит отдельно в `knowledge/taxes/`:

- `codex_2026/` — Налоговый кодекс РК 2026 (Закон №214-VIII от 18.07.2025), полный текст
- `KZ_2026.md` — методическая выжимка налогов для Wiki/QC
- `usn_forbidden_okeds_2026.md` + `.yaml` — Постановление №970 со списком 184 ОКЭД, запрещённых для УСН
- `maslihats/` — решения маслихатов городов о ставках УД
- `minfin_orders_695_2025/` — Приказ Минфина №695 со всеми формами налоговой отчётности

## Иерархия истин

```
codex_2026/                        ← первоисточник (Закон)
        ↓
data/external/kz_tax_constants_2026.yaml    ← SoT для кода
        ↓
knowledge/taxes/KZ_2026.md         ← методическая выжимка для RAG
```

При расхождении — codex побеждает yaml, yaml побеждает md.

Для законов в `laws/` — это сами первоисточники, методических выжимок пока нет (могут появиться по мере необходимости).
